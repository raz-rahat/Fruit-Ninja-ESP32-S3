# 🍉 ESP32-S3 Fruit Ninja (MPU6500 Motion Controller)

ESP32-S3 N16R8 এবং MPU6500 সেন্সর ব্যবহার করে তৈরি একটি মোশন-কন্ট্রোলড "ফ্রুট নিনজা" গেম। সেন্সরটি হাতের মুভমেন্ট ট্র্যাক করে সরাসরি ব্রাউজারে থাকা গেমে ইনপুট পাঠায়। 

## 🚀 গেমের ফিচারস
* **বিল্ট-ইন ওয়েব সার্ভার:** গেমের সম্পূর্ণ ইন্টারফেস (HTML/Canvas) ESP32-এর ভেতরেই হোস্ট করা হয়েছে এবং এটি পোর্ট 80 তে কাজ করে।
* **রিয়েল-টাইম মোশন ট্র্যাকিং:** MPU6500 (Gyroscope এবং Accelerometer) সেন্সরের ডেটা ব্যবহার করে রিয়েল-টাইম মোশন ট্র্যাক করা হয়।
* **ফ্রুট স্লাইসিং:** ১৫টি ভিন্ন ভিন্ন ফ্রুট (🍎🍊🍉🍌🍐🍇🥝🍓🍍🥭🍑🍋🍈🥥🍒)
* **বার্ড এভয়েডেন্স:** পাখি (🐦🐤🦜🐧🦉) স্লাইস করলে পয়েন্ট কাটা যায় (২২% চান্স)
* **কম্বো সিস্টেম:** পরপর ফ্রুট স্লাইস করলে কম্বো বাড়ে, স্কোর মাল্টিপ্লায়ার হয়
* **স্কোরিং:** বেস ১০ পয়েন্ট + কম্বো × ২
* **গেম ডিউরেশন:** ৬০ সেকেন্ড
* **ডেঞ্জার জোন:** শেষ ৩ সেকেন্ডে লাল ওভারলে দেখায়
* **স্মাউস-লাইক মোশন:** গাইরোস্কোপ (Gyro X/Y) দিয়ে কার্সর কন্ট্রোল
* **টিল্ট এক্সিলারেশন:** অ্যাক্সিলেরোমিটার টিল্টে স্পীড বাড়ে
* **রিয়েল-টাইম স্লাইস ডিটেকশন:** কার্সর পাথ বরাবর ফ্রুট কাটা যায়
* **ব্লেড ট্রেইল:** ৪৫০px লম্বা গ্লোয়িং ট্রেইল
* **অটো ক্যালিব্রেশন:** গেম শুরুর আগে ৩ সেকেন্ড কাউন্টডাউনে ক্যালিব্রেট হয়
* **ব্রাউজার থেকে ক্যালিবারেশন:** ব্রাউজার গেমের UI থেকেই একটি ক্লিকে সেন্সরকে ক্যালিবারেট (Calibrate) করার সুবিধা রয়েছে।

## 🛠 প্রয়োজনীয় কম্পোনেন্ট
* ESP32-S3 (N16R8) ডেভেলপমেন্ট বোর্ড
* MPU6500 6-DoF সেন্সর মডিউল (Gyroscope + Accelerometer)
* জাম্পার ওয়্যারস (Jumper Wires)

## 🔌 পিন টু পিন কানেকশন ডায়াগ্রাম
প্রজেক্টটিতে I2C প্রোটোকল ব্যবহার করা হয়েছে। ESP32-S3 এবং MPU6500 এর কানেকশন ডায়াগ্রাম নিচে দেওয়া হলো:

| MPU6500 Pin | ESP32-S3 Pin |
|-------------|--------------|
| VCC         | 3.3V         |
| GND         | GND          |
| SDA         | GPIO         |
| SCL         | GPIO 9       |

## 🔀 ভার্সন পার্থক্য (Hotspot vs WiFi)

ব্যবহারের সুবিধার ওপর ভিত্তি করে কোডের দুটি আলাদা ভার্সন তৈরি করা হয়েছে:

### ১. Hotspot Version (AP Mode)
এই ভার্সনে খেলার জন্য কোনো ইন্টারনেট বা রাউটারের প্রয়োজন নেই। 
* **নেটওয়ার্ক:** ESP32 নিজেই একটি ওয়াইফাই হটস্পট তৈরি করে। 
* **SSID:** `FruitNinja`
* **Password:** `12345678`
* **কীভাবে খেলবেন:** আপনার ফোন বা পিসি দিয়ে ওপরের ওয়াইফাইয়ে কানেক্ট করুন। এরপর ব্রাউজারে ফিক্সড আইপি `http://192.168.4.1` লিখে গেমে প্রবেশ করুন।

### ২. WiFi Version (STA Mode)
এই ভার্সনে গেমটি আপনার লোকাল ওয়াইফাই নেটওয়ার্কের অধীনে চলে।
* **নেটওয়ার্ক:** ESP32 আপনার বাসার রাউটারের সাথে কানেক্ট হয় (যেমন কোডে `RAZ` নেটওয়ার্ক দেওয়া আছে)।
* **mDNS সাপোর্ট:** এই ভার্সনে mDNS প্রোটোকল যুক্ত করা হয়েছে, তাই আপনাকে কোনো IP Address মুখস্থ রাখতে হবে না।
* **কীভাবে খেলবেন:** যে রাউটারে ESP32 কানেক্ট করা আছে, সেই একই রাউটারে পিসি/ফোন কানেক্ট করে ব্রাউজারে `http://fruitninja.local` লিংকে গেলেই গেম চালু হয়ে যাবে।
